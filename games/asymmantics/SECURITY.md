# Security Policy

## Supported version

Only the most recent published Asymmantics Beta build is supported.

## Reporting a vulnerability

Do not disclose a suspected vulnerability publicly before the project owner
has had a reasonable opportunity to investigate it.

Report security concerns privately through the official KGB Arcade project
contact channel. Include:

- the affected build or URL;
- steps to reproduce;
- observed and expected behavior;
- likely security impact;
- relevant screenshots or logs, with secrets and personal information removed.

Do not perform destructive testing, access another person's data, degrade the
service, or exceed the minimum testing necessary to demonstrate the issue.

## Current architecture

The beta is a static client-side PWA. It has no application backend, account
system, payment processing, or gameplay-data API. Hosting and repository
security remain dependent on the configuration of GitHub and the production
web host.
