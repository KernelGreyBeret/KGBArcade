# Privacy Notice — Beta

The current Asymmantics Beta runs locally in the player's browser.

The included build:

- does not require an account;
- does not request access to location, camera, microphone, contacts, or files;
- does not include analytics, advertising, tracking pixels, or third-party
  telemetry;
- does not transmit puzzle responses to a server;
- uses a service worker and browser cache only to support installation and
  offline play.

A hosting provider, content-delivery service, domain provider, or web server
may independently retain ordinary connection logs such as IP address,
timestamp, requested path, browser user-agent, and error information according
to that provider's own configuration and policies.

This notice must be reviewed and updated before adding accounts, cloud saves,
analytics, crash reporting, advertising, multiplayer features, feedback
submission, or any other collection or transmission of user data.
