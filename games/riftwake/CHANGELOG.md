# Riftwake: Signal Skimmer — Changelog

## 1.0.0 — 2026-08-30

Canonical KGBA public release.

### Preserved from the historical Signal Skimmer line
- Nosefire firing model.
- Pointer/Mouse Aim mode.
- WASD and arrow movement.
- Mobile aiming.
- Arena boundary clamps.
- Browser-native/PWA packaging intent.

### Arcade-True release pass
- Replaced gameplay-affecting random encounter generation with one authored, repeatable attack cycle per difficulty.
- Added deterministic cycle escalation: the pattern stays learnable while timing and pressure increase.
- Added signal-core skimming and clean-kill chain multiplier.
- Added immediate retry, persistent best score, pause/background pause, and persistent sound setting.
- Added mobile dual-zone controls while keeping desktop controls fully playable.
- Gameplay randomness does not determine enemy entrance, formation, or survival-critical events.
