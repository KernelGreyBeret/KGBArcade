# Jungle Breakout — Changelog

## 1.0.0 — 2026-08-30

Canonical KGBA public release.

### Source lineage
Promotes the real `Jungle Breakout v0.11 — Readability Graphics Pass` line to a clean public v1 release.

### Mudline Run
- Preserves the authored **1,180 meter** Level 1 identity.
- Preserves the fixed trail-section sequence and authored hazard route.
- Hazards include mud, bananas, logs, vines, rocks, trees, relics, creek/ravine jumps, and trail-lane collapse.
- Retains left/right, jump, duck, brake, and boost as distinct problem-solving controls.
- Retains the jaguar-gap pressure model as the central chase mechanic.

### Arcade-True release decisions
- Mudline Run is the only v1 course because it was the only fully authored course in v0.11.
- Removed the three empty locked level placeholders from the public game UI.
- Canopy Cutback, Ravine Teeth, and Temple Runoff remain planned real course updates.
- No gameplay randomization changes hazard locations or trail topology.
- Fail messages explicitly teach the relevant retry lesson.
- Added persistent best score, difficulty/pressure choice, sound toggle, pause/background pause, and immediate retry.

### Public versioning
Historical v0.x iteration remains in this changelog. Public release line begins at `v1.0.0`.
