# Contributing

Asymmantics is currently a proprietary, closed-development beta.

Public pull requests and code contributions are not automatically accepted.
Please open a discussion or contact the project owner before preparing a
substantial contribution.

Bug reports and focused playtest feedback are welcome. Useful reports include:

- the device and browser;
- the deployed build;
- the exact signal exchange preceding the issue;
- expected and observed behavior;
- whether the issue reproduces after restart.

Submitting an issue, suggestion, or pull request does not change the ownership
or license of the existing project. Any code contribution that may be accepted
will require explicit agreement on contribution and licensing terms before
merge.
