# Kid Jam — Changelog

## 1.0.0 — 2026-08-31

Canonical KGB Arcade public release wrapper around the existing **Kid Jam Beat Party** PWA.

- Canonical product name: **Kid Jam**
- Existing repository route `/games/kids_mash/` preserved for compatibility.
- Existing music-play runtime is not rewritten.
- Preserves one-tap beat generation, horn keys, game keys, SFX pads, recording, WAV save, and offline support.
- Adds standardized `game.json`, provenance, release metadata, PWA screenshots, versioned service-worker cache, and release smoke test.
