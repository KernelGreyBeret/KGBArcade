# Changelog

All notable changes to the distributed beta package should be recorded here.

## Beta 0.1 — 2026

### Added

- Installable Progressive Web App package.
- Offline application shell through a scoped service worker.
- Android and standalone-display metadata.
- KGB Arcade application icons.
- Install prompt support where provided by the browser.
- Repository license, notice, privacy, security, contribution, and
  third-party notice files.

### Game baseline

- Fixed terminal interface.
- Tri-state high, low, and off signal composition.
- Distinct source and player transmissions.
- Last-signal waveform rendering.
- Progressive sequence, echo, and relational puzzles.
- Consistent response grammar.
