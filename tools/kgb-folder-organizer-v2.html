04 / MOVE PLAN
Choose a folder to build an organization plan.
Organizer uses direct file-system access. Artifact matching is filename-based and heuristic, so review the dry run before executing. For portability, moves are performed as copy → size verification → source delete. If a copy cannot be verified, the original is left untouched.

KGB Folder Organizer only creates destination folders inside the folder you selected (or inside existing parent folders in recursive bundle mode). Existing folders are not renamed or deleted.
